팬이 운영하는 비공식 작성 도구입니다. 문의는 GitHub 문의 창구를 이용하십시오. 공개 이슈에 신고 내용·이메일 주소·첨부파일·Google 접근 정보를 올리지 마십시오.

1. 서비스와 목적

FAN REPORT는 팬이 만든 비공식 신고 메일 작성 도구입니다. 소속사와 관계가 없으며 신고 접수기관도 아닙니다. 사용자가 게시물 정보를 정리하고 자신의 Gmail로 직접 발송하는 기능을 제공합니다.

2. 작성 과정에서 다루는 정보

  • 받는 주소, 참조(CC), 숨은 참조(BCC)
  • 게시 일시, 플랫폼, URL, 작성자·계정, 게시물 내용
  • 사용자가 선택한 이미지·영상 등 첨부파일, 편집한 제목·본문
  • Google 연결을 선택한 경우 발송 권한을 사용하는 임시 접근 정보

이 정보는 메일 작성·미리보기·최종 확인·발송에만 사용합니다. 신고 내용이나 토큰을 사이트 운영자 서버에 제출하지 않으며 localStorage, sessionStorage, IndexedDB, 쿠키에 저장하지 않습니다. 입력 수집, 세션 녹화, 광고 추적 기능은 없습니다. 중복 발송을 줄이기 위해 현재 페이지에서 최근 발송 내용을 비교하는 해시 값만 임시로 보관합니다. 이 값은 다른 사이트나 서버에 보내지 않으며 새로고침하면 초기화됩니다.

3. 임시 처리와 삭제

작성 자료는 현재 페이지에서 임시로 다룹니다. 앱은 선택한 원본 파일을 기기에 새로 저장하거나 원본을 삭제하지 않습니다. 파일 삭제 버튼은 첨부 목록에서만 제거합니다. 새로고침하면 앱의 작성 상태가 초기화됩니다. 페이지를 벗어나면 앱의 Gmail 연결 정보를 버리고 다시 연결하도록 합니다. 브라우저의 뒤로가기 캐시·세션 복원 기능 등에 따라 화면이 복원될 수 있으며, 브라우저·기기 자체의 기록까지 이 사이트가 통제하지는 않습니다.

4. Google 연결과 메일 발송

Google 연결을 선택하면 Google Identity Services와 통신합니다. 이 과정에서 IP 주소, 브라우저 정보, 사이트 출처 등 일반 통신 정보가 Google에 전달될 수 있습니다. 필요한 권한은 Gmail 발송용 gmail.send 하나입니다. 앱은 Gmail 비밀번호를 받지 않으며 메일함이나 연락처를 읽지 않습니다. Google이 제공한 임시 접근 정보를 현재 페이지에서 사용하고, 영구 저장하거나 갱신 토큰을 요청하지 않습니다.

수신자·본문·첨부를 최종 확인하고 실제 발송 버튼을 누르면 사용자의 기기에서 Google Gmail API로 메일을 전송합니다. 받는 주소·CC·BCC로 지정한 사람들에게 내용과 첨부가 전달되고 본인 Gmail 보낸메일함 및 수신자의 메일함에 남습니다. 발송 후 메일 보관·삭제는 해당 Gmail 계정, 수신자 및 Google 정책에 따릅니다. 작성 도구의 첨부 삭제·새로고침으로 이미 보낸 메일을 회수하거나 삭제할 수 없습니다.

Google API로 다루는 정보는 사용자가 선택한 발송 기능에만 사용합니다. 광고, 판매, 다른 목적의 프로파일링 또는 AI 학습에 사용하지 않습니다. Google API Services User Data Policy 및 Limited Use 요건을 준수합니다.

사용자가 선택한 Google 서비스로 브라우저에서 직접 전송됩니다. Google 서비스의 처리 위치·보관·권리 행사 방식은 Google 개인정보처리방침과 계정 설정에 따릅니다. 사이트 운영자는 신고 자료나 토큰을 수신하지 않습니다.

5. 연결 해제와 문의

6. 호스팅 및 접속 기록

이 사이트는 GitHub, Inc.의 GitHub Pages로 제공합니다. GitHub는 로그인 여부와 관계없이 방문자의 IP 주소를 보안 목적으로 기록·저장한다고 안내합니다. 호스팅 제공 과정의 정보는 GitHub의 정책에 따라 처리되며 운영자가 별도의 접속 분석 기능을 설치하지 않습니다. 신고 본문·첨부파일·Gmail 토큰을 GitHub에 전송하지 않습니다.

기록의 보관 기간 및 처리 위치는 운영자가 지정하지 않으며, 확인되지 않은 기간이나 위치를 임의로 보장하지 않습니다. 구체적인 처리 및 권리 행사 방법은 GitHub 개인정보처리방침과 Pages 접속 기록 안내를 확인하십시오. GitHub 문의 창구에 이용자가 직접 게시한 정보도 GitHub 정책에 따라 공개·처리됩니다.
